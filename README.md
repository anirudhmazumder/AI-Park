# HDAC6–Alzheimer's Disease Knowledge Graph

This repository contains the curated molecular relationships, article metadata,
and graph analysis and visualization code for our manuscript,
*Literature-Based Knowledge Graph of Histone Deacetylase 6 in Alzheimer's Disease
Using Large Language Models* (Mazumder et al.).

HDAC6 participates in several processes relevant to Alzheimer's disease,
including microtubule regulation, protein quality control, autophagy, and
inflammatory signaling. Knowledge of these interactions is spread across the
literature. In this study, we developed a method to connect reported molecular
relationships together into a knowledge graph to examine how they connect and
where gaps remain.

We processed 106 full-text PubMed articles published between 2008 and 2025 using
GPT-4.1-mini, followed by entity standardization and AI-assisted manual
curation. The final dataset contains 760 subject–predicate–object triplets.
After graph-level entity normalization, these relationships form a graph of
508 molecular entities and 511 edges. Several triplets can support the same
edge, so the triplet and edge counts differ.

The scripts provided here begin with the curated triplets. They build the
graph, calculate its properties, identify community modules, and generate the
network visualizations. The literature acquisition, text preprocessing,
extraction, and curation procedures are described in the manuscript and its
Supplementary Methods.

## Repository contents

Two files at the repository root are shared by the analysis and figure scripts:
`kg_graph.py` loads the data and constructs the graphs, and `kg_plot.py` provides
the plotting functions. `requirements.txt` records the package versions used
for the manuscript.

### Data

The `Final_KG/` directory contains the curated relationships and files used to
build and inspect the graph.

| File | Contents |
| :--- | :--- |
| `set_{1..5}_filtered_triplets_cleaned.json` | Five batches containing the 760 curated triplets and their entity mappings. |
| `metadata.csv` | Titles, authors, publication dates, PubMed links, and journal impact factors of the 106 articles in the processed corpus. The `FileName` field links each article to the triplet files. The `Notes` field gives the impact-factor source where one was recorded. |
| `triplets_flat.csv` | The 760 triplets in a single table, generated by `KG_Analysis/export_flat_triplets.py`. |
| `node_details.csv` | Each node's degree, number of source papers, sample connections, and up to three source papers, generated by `KG_Visualization/colored_kg.py`. |
| `node_positions.json` | Saved layout coordinates used to reproduce the manuscript figures. |

### Analysis

| Path | Purpose |
| :--- | :--- |
| `KG_Analysis/graph_statistics.py` | Calculates graph size, density, degree statistics, connectivity, centrality, clustering, path length, community modules, and subgraph sizes. |
| `KG_Analysis/module_analysis.py` | Runs community detection and exports the results for each module. |
| `KG_Analysis/module_output/` | Contains module summaries, node lists, paper lists, and node-to-module assignments. |
| `KG_Analysis/export_flat_triplets.py` | Combines the curated triplets into `Final_KG/triplets_flat.csv`. |

### Visualizations

| Path | Purpose |
| :--- | :--- |
| `KG_Visualization/colored_kg.py` | Generates an interactive view of the full graph and exports `Final_KG/node_details.csv`. |
| `KG_Visualization/module_colored_kg.py` | Generates the full graph colored by community module (Figure 2). |
| `KG_Visualization/colored_subgraphs.py` | Generates the HDAC6, Tau, and HDAC2/HDAC4/SAHA subgraphs (Figures 3–5), along with the impact-factor and hub-focused subgraphs (Supplementary Figures S1–S2). |
| `KG_Visualization/colored_timescale_graph.py` | Generates an animated HTML view of graph growth by publication year (Supplementary Video S1). |
| `KG_Visualization/Saved_Visualizations/` | Contains annotated PNGs. The `manuscript/` subdirectory holds the figures as they appear in the manuscript. |

## Installation and use

The analysis uses Python 3 with NetworkX, NumPy, and Plotly. We used Python 3.13,
NetworkX 3.6.1, NumPy 2.5.4, and Plotly 7.1.0 for the manuscript; the package
versions are pinned in `requirements.txt`. SciPy is needed only to recompute the
layout. Static PNG export requires Kaleido and Chrome.

Install the dependencies from the repository root:

```bash
pip install -r requirements.txt
```

To calculate the graph statistics, run:

```bash
python3 KG_Analysis/graph_statistics.py
```

The script prints the graph statistics, hub rankings, module counts, and
subgraph sizes. Add `--json FILE` to save the results as JSON.

The remaining analysis and visualization scripts can be run as follows:

```bash
# Identify community modules and export their summaries
python3 KG_Analysis/module_analysis.py

# Export the curated triplets as a single CSV table
python3 KG_Analysis/export_flat_triplets.py

# Generate the full interactive graph and node details
python3 KG_Visualization/colored_kg.py

# Generate Figure 2
python3 KG_Visualization/module_colored_kg.py

# Generate Figures 3–5 and Supplementary Figures S1–S2
python3 KG_Visualization/colored_subgraphs.py

# Generate the animation for Supplementary Video S1
python3 KG_Visualization/colored_timescale_graph.py
```

These commands assume the repository root is the working directory, although
the scripts can also be called from other directories using their paths.

Interactive HTML files are written to
`KG_Visualization/Final_Visualizations/`, which is not tracked in the repository.
For figure export, `--png` also saves annotated PNGs in
`KG_Visualization/Saved_Visualizations/`. The `--manuscript` option saves the
plot-area-only PNGs used in the paper in
`KG_Visualization/Saved_Visualizations/manuscript/`, and `--label-size` sets the
node-label font size. Use `--open` to open the HTML output in a browser.

For example, to generate Figure 2 and its manuscript PNG:

```bash
python3 KG_Visualization/module_colored_kg.py --manuscript
```

## Graph construction and interpretation

### Entities and relationships

Nodes represent molecular entities, including proteins, small molecules, and
complexes. Protein annotations were standardized using UniProt during
post-processing. When constructing the graph, entity names undergo Unicode
NFKD normalization, lowercasing, removal of non-alphanumeric characters, and
whitespace collapsing. A leading "class I" is also removed, "tau protein" is
mapped to "tau", and "amyloid beta" and "beta amyloid" are unified. These steps
reduce 572 entity strings to 508 nodes. The displayed name is the spelling with
the fewest special characters, with shorter names preferred when tied.

One triplet involving the generic term "microtubules" is excluded from graph
construction. Each distinct pair of entities forms one undirected edge,
regardless of how many triplets support it. In-degree and out-degree are
calculated separately using the subject-to-object orientation of the triplets.

Edge colors indicate the relationship category: red for activating or binding
relationships, blue for inhibiting or degrading relationships, and black for
predicates the language model could not classify. Where several triplets
support an edge, its color follows the category of the first triplet in
processing order.

### Graph statistics

NetworkX is used to calculate density, degree centrality, normalized unweighted
betweenness centrality, connected components, and the average clustering
coefficient across the whole graph. Average shortest path length is calculated
within the largest connected component. Degree summaries use NumPy, with the
population standard deviation. Components containing at most five nodes are
counted as small islands.

### Community detection

Community detection uses the NetworkX Louvain implementation on the largest
connected component, with unweighted edges, resolution 1.0, modularity threshold
1e-7, and random seed 42.

To reproduce the 27 modules reported in the manuscript, `module_analysis.py`
uses `kg_graph.build_module_graph` by default. This graph uses a lighter form
of entity normalization: Unicode NFKC normalization, lowercasing, unification of
dash characters, and whitespace collapsing, without the synonym rules used for
the full graph. This produces a graph of 526 nodes and 526 edges, with 371
nodes in the largest connected component.

For Figure 2, each node of the full graph is colored by the module of its
counterpart in the module graph
(`KG_Analysis/module_output/module_assignment_canonical.csv`). Because the
module graph merges fewer spellings, a single full-graph node can correspond to
several module-graph nodes; if those fall into different modules, the node takes
the module of the largest one.

### Subgraphs

The impact-factor subgraph retains edges supported by at least one paper from
a journal with an impact factor of 10 or greater. The hub-focused subgraph
contains the ten highest-degree nodes and all their direct neighbors. The
HDAC6, Tau, and HDAC2/HDAC4/SAHA views contain the named entities and their direct
neighbors in the full graph.
